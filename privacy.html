Privacy Policy – Clipper

Last updated: 20 November 2026

Clipper is a private tool used only by the owner of the Clip Rush TV YouTube channel. It is not offered to other users.

What Clipper accesses

With the owner's permission (Google OAuth), Clipper uses the YouTube Data API and the YouTube Analytics API to:

  • upload videos the owner approved to the owner's own YouTube channel, with their title, description and tags;
  • post a comment on those videos;
  • read the channel's own video list and statistics (views, likes, comments, average view duration) to see which clips perform best.

What Clipper stores and shares

The OAuth token and the statistics are stored only on the owner's own computer. Clipper does not sell, share or send this data to anyone else, and does not use it for advertising. It does not access any other user's data.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is also subject to the YouTube Terms of Service and the Google Privacy Policy.
